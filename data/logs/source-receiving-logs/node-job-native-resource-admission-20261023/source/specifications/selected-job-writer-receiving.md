## Native observation

Only the exact declared unit names unitPrefix + '-job-' + id + '.service' may be read. Use qualified native systemd user-manager tools with closed argv, finite timeout and output bounds. Receive Id/LoadState/ActiveState/SubState/Job/MainPID/ControlPID/InvocationID/ControlGroup, main lifecycle/result, working directory and typed ExecStart/ExecStopPost. Only whitelisted NODE_JOB_ID/UNIT/RELEASE/STARTED_AT/DEMAND values may leave any native environment parser. Never expose environment, journal text, credential contents or output tails.

For actual named PIDs, read only their own stat birth/cmdline/exe/cwd/cgroup. Receive captured cgroup population, including descendants/finalizer/recorder; empty main PID alone is insufficient. Re-receive unit identity after process/evidence reads. A changed snapshot is unknown, never a positive prefix. A current job/control transaction, running main/control process or populated cohort remains running/queued/unknown as appropriate.

Classify observation separately from outcome:
- absent: native not-found/unloaded and no current selected job/process evidence; no successful historical outcome follows;
- queued: an actual native Job/control transaction is present;
- running: a live selected main/finalizer/recorder/cohort is observed;
- inactive: no current Job/main/control/running state/populated cohort in the received native snapshot; history remains a separate axis;
- unknown/refused: mismatched source, changed/native-unavailable/truncated/redirected/corrupt evidence, unexplained remaining cohort or unreceived identity.

If a transient unit is collected, preserve absent/unknown distinction. The absent classification requires the complete native property shape; an actual not-found response that omits service properties remains unknown. Complete injected absent fixtures qualify the conditional classifier, not a claim that every native not-found response supplies those properties. No unit list or count can infer that every historical run finished. No future-admission fence is claimed by observation.
