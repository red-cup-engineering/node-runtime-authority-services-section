# Computer code engineering services section

Owns services whose primary subject is computer code, including programming
languages and the development systems that produce, examine, version, and
deliver code.

The content-address source-domain audit is owned by the independent Data
library `@red-cup-engineering/semiotic-content-address/audit`, mounted at
`computer-data-engineering-services-section/lib/semiotic-content-address`.
Computer Code continues to own general-purpose source introspection and
package/repository normalization, not a duplicate content-specific scanner.
