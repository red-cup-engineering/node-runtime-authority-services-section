# Deployment Formation Contracts

Pure, provider-neutral lifecycle laws for customer-specific public delivery formations. The package records bounded solicitation, exact provider offer, customer acceptance, custody reference, digest-bound artifact, separately settled provider receipt residues, independent external assay, and cutover admission.

It contains no provider SDK, CLI, shell execution, credentials, or raw secrets.

`canonical-record` gives every provider and consumer the same JSON byte law and
content identity. `compose` applies the complete formation in order and returns
either the first typed refusal or one closed formation. Provider adapters still
own effects; this package owns only the portable evidence contract between
them.
