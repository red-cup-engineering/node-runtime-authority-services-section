# Wave 1 Design — Settling Daemon + Workbench (ways-purist pressure)

Design only. Buildable against post-refactor `lib/meme-topology` (Attestation-named surface, `induce`/`extend`/`affirm`/`deny`/`specializes` facade). Each section marks where fidelity to the nine ways costs operability — costs are accepted, not negotiated away, but they are priced.

## 0. Package layout (one engine, two shells — Way 7)

- **`lib/meme-topology-world`** — the shared organ both bodies consume: `WorldHandle` (open/admit/tick/read/render/mount) over persistence + admission + the lib's settling. This is NOT a second engine; it contains zero closure operators. It is the fold(log) shell around `induce`.
- **`lib/meme-topology-codecs-jsonl`** — the witness-log codec (Attestation ↔ canonical JSONL line), per the `lib/<thing>-codecs-<standard>` convention. A site morphism: decode is pullback/admission, encode is pushforward, residue reported.
- **`services/meme-topology-daemon`** — HTTP/process shell over `meme-topology-world`.
- **`apps/meme-topology-workbench`** — interactive shell over `meme-topology-world` (local mode) or over the daemon's HTTP surface (attached mode).

Kind-string discipline carried through (Way 6): `meme-topology.world.transaction:witness`, `meme-topology.world.admission:witness`, `meme-topology.world.admission-obstruction` (quarantine), `meme-topology.world.tick:witness`, `meme-topology.daemon.snapshot.carrier`, `meme-topology.world.mount:witness`. Every kind names its derivation.

## 1. The daemon

### 1.1 Process model: the diffusion run as a process

The daemon is `fold(log)` made resident. Identity of the process:

- **At rest**: a root directory under the `meme-topology-addressing` codec. Per-subject JSONL logs at `address(root, term, "jsonl")` (posix-holography flatfile contract: canonical bytes, O_APPEND, fsync-before-resolve, torn-line tolerance, ENOENT→[]). One transaction log at the daemon's own addressed term. Nothing else is durable. Carriers are never serialized — the log is the truth, every carrier is a reading (Way 1).
- **On boot**: stream the transaction log, decode attestations (codecs-jsonl), `induce(all)` → standing `MemeTopologyCarrier`. Boot is a **limit-ordinal advance**: the replay is one 1-cell "advance by λ" in the temporal 2-category, witnessed as a `tick:witness` whose payload names the replayed transaction range. Cost: boot is O(history). Accepted; a checkpoint is permitted *only* as a cache of a reading (Way 1 explicitly licenses this), keyed by transaction high-water mark, and is discarded on any disagreement with replay.
- **Running**: a standing `WorldHandle { carrier, ordinal, mounts, cursor }`, all fields recomputable from the log. The daemon's own runs, admissions, quarantines, errors, and mounts are attestations in a reserved namespace (`composeTerm("meme-topology.world", [...])`) inside the same world it settles (Way 9). There are **no mutable private-field counters**: `runs` is the count of `tick:witness` cells; `lastError` is the latest error cell; the snapshot endpoint is a declared reading over the daemon's own trace. The newswire `#runs`/`#lastError` habit is rejected.

**Time.** The daemon ordinal is carried as a **term**, not an integer: a serialized ordinal grammar `{ form: "zero" } | { form: "successor", of } | { form: "limit", label, sequence: <term-coded> }`. A normal tick is a successor advance; replay/compaction are labelled limit advances. This admits `α + β` composite advances later (the 2-category's 1-cells) without a wire change. Cost: heavier than an integer on every wire shape; accepted — the linear counter is the strict-regime shadow and may be served as a *rendering* (`depth: number`) alongside the term, never instead of it (Way 5).

**No scheduler in the engine.** There is no `setInterval` anywhere in the tick path. A tick fires when an admitted transaction is pending — witness-driven, period. Timers exist only as one **conduit** among many (see mounts): a timer conduit *generates witnesses* ("poll observed conduit X; wall-clock reading T attached as payload"), which then pass admission like anything else. Wall-clock appears exclusively as witnessed testimony inside attestation payloads and provenance receipts — never as sequencing, run identity, or transaction T (Way 2). Cost: a freshly booted daemon with no conduits mounted does literally nothing. Correct: no witness, no world.

### 1.2 Admission path (Way 4, enforced where the lib doesn't)

The lib admits unprovenanced attestations (`provenance?: unknown`); the gate is the daemon's job, and it is a **charge-producing morphism**, not a validator:

```
ProposedAttestation → shape check → provenance verification → one of:
  ADMITTED    affirm-side admission:witness; joins the pending transaction
  QUARANTINED admission-obstruction; appended to the quarantine log; held inert
```

- **Shape failure is the only exception path** (malformed bytes, codec residue above declared tolerance → HTTP 422). Every *domain* outcome — including "we don't recognize this witness" — is a value with evidence (Way 3/4). Quarantine is never deletion: quarantined attestations live at an addressed term, content-keyed, and a later witness establishing their provenance re-presents them for admission as a new monotone tick. Rejection is evidence; spam is held inert, not destroyed.
- **Provenance verification** = causal-path check, not field-presence check (the memetics habit of carrying-but-never-checking `TraceWitness` is rejected). A provenance is valid iff it names an **observer that is itself a settled cell in the world** — admitted via a mount or via the genesis axiom. Each mount may declare a stricter verifier (signature, capability token via posix-holography `guardAccess`), but the verifier is data in the mount manifest, and its verdict is recorded as the admission witness's payload.
- **Bootstrap axiom (flagged)**: the genesis observer is the one thing admitted without a prior witness — declared in daemon config and immediately written as the first transaction, so even the axiom leaves a trace. This is the unavoidable floor of Way 4 and is marked as such in the manifest kind: `meme-topology.world.genesis:witness`.
- **Identity** is canonical content: `attestationKey = termKey(canonical encoding)` (codecs-jsonl). Duplicate admission is idempotent (G-Set semantics, the flatfile discipline). Batches are **transactional**: one transaction record (one JSONL line listing member attestation keys + the admission receipts) is the unit of folding; per-subject rows orphaned by a crash before the transaction line are visible-but-unfolded residue, reported by the audit reading, never half-settled. This supersedes posix-holography's per-datom append.

### 1.3 Settling loop

```
tick(world, { fuel? }):
  1. seal the pending transaction (append transaction:witness line, fsync)
  2. settle: resumeSettling(world.carrier, delta, { baseOrdinal: world.ordinal, fuel })
     — warm-start from the previous fixed point joined with delta (lib seam §3.1);
       UNTIL THAT LANDS: extend(carrier, delta) full recompute, honestly tagged
  3. result is regime-tagged: { regime: finite|scott|transfinite|aperiodic | "partial-prefix" }
     — fuel exhaustion NEVER reported as settlement (settling-orbit discipline kept verbatim)
  4. compute the tick readings: settlingClosureEquivalence(prev, next), cell-charge delta
     (lib seam §3.2), classifySettling, H¹ ranks (settlingFirstCohomology + per-reading
     cohomology), gap vanishing
  5. append tick:witness { ordinal-term advanced, regime, equivalence verdict, fuel spent }
  6. swap world.carrier; cursor (byte offset / transaction high-water) written as a
     witnessed cell, not hidden state
```

- **Stable cells are results.** A tick that drives cells to ⊤ is a *successful* tick; nothing in the loop branches on contradiction. The only places ⊤ is treated specially are declared renderings (§1.4).
- **Partial-prefix carry-over**: a `partial-prefix` result leaves the transaction sealed and the orbit resumable; the next tick continues the same closure from the recorded valuation, advancing the same ordinal chain. The world is honestly "mid-descent," and sections served meanwhile say so (the section envelope carries the regime tag).
- **Operability cost, priced**: until incremental settling lands in the lib, every tick is O(world) — `extend` is a full `induce`, ordinals restart at zero internally, and the daemon must re-offset stage ordinals itself. Acceptable at Wave-1/Wave-2 (news vertical, archive statuses) scale; the seam (§3.1) is the fix, not a daemon workaround. The daemon must NOT splice fake continuity by mutating carrier internals.

### 1.4 Section serving (observer-relative; calm/audit as declared pushforwards)

The HTTP surface serves **readings**, never "the data":

- A section request names: a **reading** (`knowledge|truth` × `least|greatest`, or a mount-declared named reading), an **observer** (a registered, witnessed identity — observer-relative restriction to the sub-site the observer's mounts grant), and a **rendering** (`audit` or a mount-declared calm pushforward). **The rendering parameter is mandatory.** There is no default calm collapse and no unparameterized `GET /value` — Way 3's "declared, never silent" taken literally. Cost: breaks casual `curl` ergonomics; every consumer must say how it wants contradiction treated. Accepted without apology; this is the single highest-leverage purity point in the design.
- **Audit** serves the full charge per cell plus receipts: contributing attestation keys, provenance digests, gap status (closure/opening), whether the cell fired at a limit stage (H¹ generator membership).
- **Calm** pushforwards collapse to a classical shadow and **must report residue**: the response carries `residue: { collapsed: Cell[], gaps, h1Rank }` — what the pushforward killed (Way 7: no export, only pushforwards that report). `pubStatus: "usable"`-style collapse inside a carrier is structurally impossible because carriers never reach the wire.
- **Charge wire shape is algebra-tagged**: `{ algebra: "four", value: "potential"|... }` — FOUR as the named finite projection of the general residuated charge, so widening to quantale-valued charge is additive (Way 5; SWARM's "FOUR is forbidden in the core" honored at the wire even while the lib's interior is FOUR today).
- **Honest absence**: 503 with a kind-tagged unavailability body before first settlement and during boot replay; the snapshot/self endpoint is always available because it reads the daemon's own trace.

### 1.5 The mount model (Way 7: one descent, many worlds)

A mount is **data admitted as evidence**, never code with engine access:

```ts
interface MountManifest {
  readonly kind: "meme-topology.world.mount.manifest";
  readonly namespace: AddressTerm;                  // the sub-site's term prefix
  readonly vocabulary: readonly PredicateDecl[];    // marks/predicates the domain speaks
  readonly readings: readonly ReadingDecl[];        // named (order, bound, restriction) readings
  readonly renderings: readonly PushforwardDecl[];  // calm pushforwards w/ declared loss class
  readonly codecs: readonly SiteMorphismRef[];      // decode/encode pairs, residue-reporting
  readonly conduits: readonly ConduitDecl[];        // witness generators (timer, fetch, watch, webhook)
  readonly admission: AdmissionGateDecl;            // provenance verifier for this namespace
}
```

Mounting is itself a tick: the manifest is encoded as attestations (`mount:witness`) and the mount table is fold(daemon log) — a restarted daemon recovers its mounts by replay, and *unmounting is an assertion*, not a deletion. The interface has **no hook for closure operators, valuations, or settling order** — a domain physically cannot fork the engine. Conduits run as supervised tasks whose every emission passes the same admission gate (the hardwired-`ENDPOINTS` habit rejected: observers/conduits are admitted and withdrawn as witnessed facts). The H¹/`coordinationFree` reading is served per-namespace so consensus cost across a mount's observers is computed, not assumed (Way 8).

## 2. The workbench

The four gerunds made interactive; a shell over the **same** `WorldHandle`, in two modes: **local** (opens a root directory directly, single-writer advisory lock — the daemon and a local workbench never co-write a root) and **attached** (pure HTTP client of a daemon; identical verb surface).

**The session is a trace** (Way 1/9). Every workbench command is appended as a witness to a session log at an addressed term under the world root (`meme-topology.workbench.session` namespace). `fold(session)` reproduces the session; sessions are replayable as scripts — *programs are evidence* operationalized. There is **no undo**: you articulate a retraction (a `deny`), and the contradiction it may produce is shown, charged, with receipts. Cost: users coming from REPLs will reach for Ctrl-Z and find a courtroom. Accepted; the workbench's job is to teach the substrate, not to hide it.

Verb surface (each maps 1:1 to a §4 operation):

| gerund | commands |
|---|---|
| articulating | `affirm s p [o]`, `deny s p [o]`, `specializes a b` — all require `--as <observer>`; refusal without it is the teaching moment for Way 4 |
| predicating | `vocab`, `theory`, `proofs` — inspect the base/typed theory the marks have generated |
| positing | `induce` (fresh), `seed --bound greatest` — show the seed valuation before time runs |
| settling | `tick [--fuel n]`, `watch` (stage-by-stage orbit: ordinal, shape initial/successor/limit, designated cells, firings — the settling timeline rendered as the 4d block's time axis), `regime`, `h1`, `gap` |
| reading | `read <reading> [--at s.p.o]` (full charge + receipts), `render <pushforward>` (shadow + residue table), `equiv <ordinal-a> <ordinal-b>` |
| mounting | `mount <manifest.json>`, `mounts`, `quarantine` (inspect held-inert witnesses, `re-present <key>` after provenance arrives) |

Charge words (`AFFIRMED/DENIED/CONTESTED/UNSETTLED`) and colors appear **only** in the terminal renderer, computed at the print edge from the bilattice value — the swarm.mjs discipline. The workbench never stores a collapsed word.

## 3. The seam: what lib/meme-topology must expose (gaps flagged)

What exists and is sufficient: `induce`/`extend`, `affirm`/`deny`/`specializes` + `AdmissionOptions.provenance`, `fixedPoints` + `fixedPointReadings` + `readCharge`, `knowledgeClosureSettling`, `classifySettling`, `settlingClosureEquivalence`, `settlingFirstCohomology`, `fixedPointGap`, `cohomology`, and the exported warm-start seam (`predicationValuationClosureProcess`/`closePredicationValuationClosure`). Addressing (`termKey`/`segment`/`address`/`logPath`/`termOf`/`composeTerm`) is complete for the path layer.

**Gaps the daemon/workbench cannot paper over** (in priority order; 1–3 block honest operation, 4–6 block fidelity):

1. **Incremental settling** (journal demand, confirmed missing): `resumeSettling(prev: MemeTopologyCarrier, delta: readonly Attestation[], options?: { fuel?: Natural; baseOrdinal?: Ordinal }): IncrementalSettlingResult`. Needs three internal helpers the survey found absent: extend a `PredicationCarrier` base with new terms; merge delta memes into an existing `Valuation` (today `composeFibers` rebuilds from the full meme list); splice the new orbit onto the prior `SettlingCarrier` so stage ordinals continue from `baseOrdinal` instead of restarting at zero. Result must be regime-tagged with `"partial-prefix"` for fuel exhaustion and must carry a resumable continuation. Until this lands the daemon ships on `extend` with depth honestly reported as restarted.
2. **Cell-level diff reading**: `settlingDelta(prev: MemeTopologyCarrier, next: MemeTopologyCarrier): readonly CellChargeDelta[]` (`{ cell, before: ChargeValue|null, after: ChargeValue }`). `settlingClosureEquivalence` answers only "same world?"; tick receipts and the trace feed need *which cells moved*.
3. **Attestation codec** (nothing serializes today; `Mark` is a class, prototype dies on JSON round-trip): `encodeAttestation(a): CanonicalJson`, `decodeAttestation(json): Attestation | CodecResidue`, `attestationKey(a): string` (= `termKey` of canonical form). Home: `lib/meme-topology-codecs-jsonl`, built on addressing's `termKey`. Decode is an admission pullback and must report residue, not throw, on tolerable loss.
4. **Site-morphism carrier** (Wave 1 demand from the journal): `SiteMorphism { kind: "meme-topology.site-morphism.carrier"; pullback; pushforward; residue(input): ResidueCharge }` — the mathematical home for codecs, calm/audit pushforwards, and federation. The daemon's `MountManifest.codecs` and the rendering layer type against this.
5. **Serializable ordinal terms**: `LimitOrdinal.fundamentalSequence` is function-valued — not persistable. Need a term-coded ordinal grammar (`ordinalTerm(o): OrdinalTerm` / `ordinalOf(term)`) covering at least zero/successor/named-limit (ω, replay-λ labels). **Flag**: fully general fundamental sequences are not serializable; the persisted grammar is a declared restriction, recorded as such.
6. **Algebra-tagged charge shape**: a wire-level `ChargeTerm = { algebra: "four", value: FourValue }` union, so FOUR is a named projection and the quantale generalization is a widening (descent-as-cosmogony's explicit demand). Pure type-and-codec work; no engine change.

Also flagged, accepted for Wave 1: `extend` = full recompute (gap 1 fixes); O(n²) scans in information/gap/cohomology (workbench-scale fine; revisit at Wave 2 archive scale); lib admits unprovenanced attestations (gate stays in `meme-topology-world` by design — the lib is the math, the world is the law).

## 4. API sketches — the load-bearing twelve

### TypeScript (`lib/meme-topology-world`)

```ts
// 1. Boot = replay = limit-ordinal advance. Never partial: throws only on malformed bytes.
export function openWorld(root: string, options: {
  readonly genesis: ObserverDecl;            // the one axiom; written as genesis:witness
  readonly lock?: "exclusive" | "attached";
}): Promise<WorldHandle>;

export interface WorldHandle {
  readonly kind: "meme-topology.world.handle";
  readonly carrier: MemeTopologyCarrier | null;   // null before first settlement — honest absence
  readonly ordinal: OrdinalTerm;
  readonly mounts: readonly MountRecord[];        // fold(log), not a registry
  readonly cursor: TransactionKey;                // witnessed high-water mark
}

// 2. Admission: charge-producing, never throwing on domain outcomes.
export function admit(world: WorldHandle, proposed: readonly EncodedAttestation[]):
  Promise<AdmissionReceipt>;                      // per-item: admitted | quarantined, each a witness
export interface AdmissionReceipt {
  readonly kind: "meme-topology.world.admission.receipt";
  readonly admitted: readonly AttestationKey[];
  readonly quarantined: readonly QuarantineEntry[]; // { key, obstruction, address } — held inert, addressable
  readonly transaction: TransactionKey | null;      // null if nothing admitted
}

// 3. The tick: seal, settle, witness. The ONLY way the ordinal advances.
export function tick(world: WorldHandle, options?: { readonly fuel?: number }):
  Promise<TickResult>;
export interface TickResult {
  readonly kind: "meme-topology.world.tick:witness";
  readonly advanced: { readonly from: OrdinalTerm; readonly to: OrdinalTerm };
  readonly regime: "finite" | "scott" | "transfinite" | "aperiodic" | "partial-prefix";
  readonly equivalence: SettlingClosureEquivalenceJudgment;
  readonly delta: readonly CellChargeDelta[];     // seam gap 2
  readonly firstCohomologyRank: Natural;          // held disagreement, surfaced every tick
}

// 4. Reading a section: observer-relative, full charge, receipts.
export function readSection(world: WorldHandle, reading: ReadingRef,
  observer: ObserverRef): SectionReading;          // throws only if reading/observer unwitnessed
export interface SectionReading {
  readonly kind: "meme-topology.world.section.reading";
  readonly at: OrdinalTerm; readonly regime: string;
  readonly cells: readonly { cell: Cell; charge: ChargeTerm;
    witnesses: readonly AttestationKey[]; gap: GapStatus; limitFired: boolean }[];
}

// 5. Rendering: the ONLY collapse point. Always returns residue.
export function render(section: SectionReading, pushforward: PushforwardRef): Rendering;
export interface Rendering {
  readonly kind: "meme-topology.world.rendering";
  readonly shadow: unknown;                        // codec-shaped classical output
  readonly residue: { readonly collapsed: readonly Cell[];
    readonly gapsKilled: Natural; readonly h1Rank: Natural };  // what the pushforward killed
}

// 6. Mounting: a manifest becomes witnesses; no code crosses this boundary.
export function mountSite(world: WorldHandle, manifest: MountManifest): Promise<TickResult>;

// 7. The trace feed: subscription = reading the log from a witnessed cursor.
export function transactions(world: WorldHandle, from?: TransactionKey):
  AsyncIterable<TransactionRecord>;

// 8. Quarantine inspection and re-presentation (retroactive admission, monotone).
export function quarantine(world: WorldHandle): AsyncIterable<QuarantineEntry>;
export function representQuarantined(world: WorldHandle, key: AttestationKey,
  provenance: EncodedAttestation): Promise<AdmissionReceipt>;
```

### HTTP (`services/meme-topology-daemon`)

```
 9. POST /witnesses          body: { attestations: EncodedAttestation[] }
                             202 → AdmissionReceipt (admitted+quarantined; quarantine is a 2xx outcome)
                             422 only for malformed shape; contradiction is NEVER an error status
10. POST /ticks              force an advance over the pending transaction (the --once verb);
                             admission also auto-enqueues a tick — the timer that used to drive
                             newswire is now just a mountable conduit that POSTs /witnesses
11. GET  /sections/{reading}/{...term}?observer=<id>&rendering=<audit|calm-name>[&cursor=]
                             rendering REQUIRED (400 with the doctrine pointer if absent);
                             audit → SectionReading; calm → Rendering with residue block;
                             503 kind-tagged before first settlement
12. GET  /regime             classifySettling + cofinality + per-reading H¹ ranks +
                             gap vanishing + coordinationFree per mounted namespace
    GET  /trace?cursor=      NDJSON stream of TransactionRecords (the federation seam)
    GET  /quarantine         audit-only reading of held-inert witnesses
    POST /mounts             MountManifest → admitted as mount:witness ticks
    GET  /self               snapshot AS a reading over the daemon's own trace
                             (runs = count of tick:witness; errors = error cells; no field state)
```

**Consolidated fidelity-cost ledger**: mandatory `rendering` param (ergonomics); ordinal-as-term on every wire shape (verbosity); O(world) ticks until seam gap 1 lands (latency, honestly tagged); O(history) boot replay (checkpoints only as discardable reading-caches); unbounded quarantine and logs (compaction deferred — it is a Landauer-priced explicit operation, never cleanup); no undo in the workbench (retraction-as-assertion); genesis observer as the single unwitnessed axiom (declared, kind-tagged, first line of the log).
