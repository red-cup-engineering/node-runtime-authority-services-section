# Relationing Category-Theory Concepts

This branch gathers the canonical and exploratory manuscripts rooted in category-theoretic treatments of Relationing.

## Concepts

- `proposing-relationing/` — canonical treatise + movements
- `formal-axioms-of-relationing/` — axiomatized reflexive existence
- `foundations-of-relation/` — supporting meta-theory
- `composing-proposing-a-relational-existence/` — exploratory composition notes
- `proposing-a-modality-of-relationing-existence/` — modality-focused draft
- `relational-posets/` — categorical poset analysis

Each concept directory contains `papers/` (and, over time, experiments/notes). Update this guide when new category-theory concepts are added.
