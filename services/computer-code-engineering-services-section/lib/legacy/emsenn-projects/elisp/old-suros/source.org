** Overview
A */suros/* is a /single-user responsive object server/. It is implemented as a collection of Elisp declarations for operating an ActivityPub-compliant (and IndieWeb-friendly) web server. It is in the earliest stages of development.

In plain English, it's an Emacs package for running a dedicated webserver.

In addition to requiring Emacs version 24 or greater, these instructions require the following Emacs packages
- [[http://eschulte.github.io/emacs-web-server/index.html][Emacs Web Server]], which provides functions for running the HTTP server and responding to requests.
- [[https://github.com/Wilfred/mustache.el][Mustache.el]], which provides functions for templating objects.
- [[https://github.com/Wilfred/ht.el][Ht.el]], which provides easier ways to declare hash tables.

This document will assume familiarity with the Emacs text-editor as a piece of software, and the following formal languages:
- Org-mode
- HTML
- CSS
- JSON
- Elisp
- Mustache

Additionally, familiarity with the following protocols, specifications, and standards is expected:
- HTTP
- ActivityPub
- IndieWeb
- Webfinger
- Webmentions

**** DRAFT Configure
Right now your suros' configuration is right there in its source - sorry, unless you're picky about it, trying to configure it from your init won't work right now. At the top of =suros.el= there's a definition for the =suros-config= hashtable - edit it carefully, but edit it to configure your suros. See [[#config]["Suros Configuration"]] for a detailed explanation of that data structure. Once you're done editing it, either =M-x evaluate-buffer= or place point (your cursor) after the last paranthesis of the configuration statement and press =C-x C-e=.
***** ActivityPub Actor
Your suros will create an [[https://www.w3.org/TR/activitypub/#actors][ActivityPub actor]] at ={{base-url}}/actor=. In order to do that accurately, you'll need to customize the following [[#configuration-variables][configuration variables]]:

- =actor-public-key= :: The public key of an RSA keypair.[fn:1]
- =user-name= :: In =@user@base.url=, this is =user=.
- =base-url= :: In =@user@base.url=, this is =base.url=.
*****  H-Card
Your suros will create an [[http://microformats.org/wiki/h-card][h-card]] at its homepage. This requires at least the following [[#configuration-variables][configuration varaibles]]:

- =proper-name= :: The name you'd prefer used in official contexts.
**** Run
To run your suros, run the command =suros-start=.

This puts a webserver up at whatever you set =base-url= and =web-port= to, such as =https://suros.emsenn.net:9000=.
**** Shutdown
To shutdown your suros, evaluate =(ws-stop-all)=. Which actually shuts down all web-servers. Whoops!

The function =suros-start= starts your suros server.
#+name: suros-start-elisp
#+begin_src elisp
    (defun suros-start ()
      "This function starts your suros."
      (interactive)
      (let ((config suros-config))
	(if (suros-validate-config config)
	    (setq suros-server-object
		  (ws-start suros-handlers
		   (ht-get suros-config "web-port")
		   (get-buffer-create "suros-log"))))))
#+end_src

More precisely, it:

- [[#validate-config-function][Validates =suros-config=]]
- Binds a web server to the =web-port= [[#configuration-variables][configuration variable]]
- Starts logging to a =suros-log= buffer.
- Listens for various requests and passes them to the appropriate handler:
  - =GET= requests are sent to [[#read-get-request-function][=suros-read-get-request=]]
  - =POST= requests are sent to [[#read-post-request-function][=suros-read-post-request=]]
  - =HEAD= requests are sent to [[#read-head-request-function][=suros-read-head-request=]]

=GET= requests are when a client is requesting a resource, =POST= requests are when they're trying to tell your suros something, and =HEAD= checks are for diagnosis.

  (defun suros-read-get-request (request)
    (with-slots (process headers) request
      (let* ((context suros-config)
	     (object (ht-create)))
	;; replace v-- with (suros-add-request-headers-to-context headers context)
	(ht-set! context "requested-path" (substring (cdr (assoc :GET headers)) 1))
	(if (ht-get (suros-flippen-flatten-ht suros-builtin-paths)
		    (ht-get context "requested-path"))
	    (funcall (symbol-function
		      (ht-get (suros-flippen-flatten-ht suros-builtin-paths)
			      (ht-get context "requested-path")))
		     (ht-create)
		     suros-config)
	  (ht-set! object :object "No path?")
	  (ht-set! object :headers (ht ("Content-type" "text/hml"))))
	(ht-map (lambda (key val)
		  (ws-response-header process 200 '(key . val)))
		(ht-get object :headers))
	(process-send-string process (ht-get object :object)))))



  (defun suros-make-debug-html-object (object context)
    (ht-set! (ht-get object :headers (funcall (lambda ()
						(ht-set! object :headers (ht-create))

	     "Content-type" "text/html")
    (ht-set! object :object "AHAHAHAHHA")
    object)

    (process-send-string process (ht-get object :object)))

***** Flippen Flatten Function
The function =suros-flippen-flatten-ht= iterates over a hashtable where each value is assumed to be a list, and returns a new hashtable where each key is an element of those lists, and each value is the corresponding key.

So, given =(ht (a '(b)) (c '(d e)) (f '(g h i)))=, returns =(ht (b a) (d c) (e c) (g f) (h f) (i f))=.
#+name: suros-flippen-flatten-ht-elisp
#+begin_src elisp
  (defun suros-flippen-flatten-ht (htable)
    (ht<-alist (-flatten-n 1 (append
			      (ht-map (lambda (key vals)
					(mapcar (lambda (val) (cons val key)) vals))
				      htable)))))
#+end_src

[fn:1] The free tool [[https://www.openssl.org/][OpenSSL]] can be used to generate an RSA keypair. From a command line: =openssl genrsa -out private.pem 2048 && openssl rsa -in private.pem -outform PEM -pubout -out public.pem==. This will create a new keypair in the current directory. The contents of =public.pem= is what should be used for =actor-public-key=, however you must replace the extant line-breaks with =\n=.
