***** Title-to-Slug

#+name: org-roam-title-to-slug
#+begin_src elisp
  (cl-defmethod org-roam-node-slug ((node org-roam-node))
    "Return the slug of NODE."
    (let ((title (org-roam-node-title node))
  	(slug-trim-chars '(;; Combining Diacritical Marks https://www.unicode.org/charts/PDF/U0300.pdf
                             768 ; U+0300 COMBINING GRAVE ACCENT
                             769 ; U+0301 COMBINING ACUTE ACCENT
                             770 ; U+0302 COMBINING CIRCUMFLEX ACCENT
                             771 ; U+0303 COMBINING TILDE
                             772 ; U+0304 COMBINING MACRON
                             774 ; U+0306 COMBINING BREVE
                             775 ; U+0307 COMBINING DOT ABOVE
                             776 ; U+0308 COMBINING DIAERESIS
                             777 ; U+0309 COMBINING HOOK ABOVE
                             778 ; U+030A COMBINING RING ABOVE
                             780 ; U+030C COMBINING CARON
                             795 ; U+031B COMBINING HORN
                             803 ; U+0323 COMBINING DOT BELOW
                             804 ; U+0324 COMBINING DIAERESIS BELOW
                             805 ; U+0325 COMBINING RING BELOW
                             807 ; U+0327 COMBINING CEDILLA
                             813 ; U+032D COMBINING CIRCUMFLEX ACCENT BELOW
                             814 ; U+032E COMBINING BREVE BELOW
                             816 ; U+0330 COMBINING TILDE BELOW
                             817 ; U+0331 COMBINING MACRON BELOW
                             )))
      (cl-flet* ((nonspacing-mark-p (char)
                                    (memq char slug-trim-chars))
                 (strip-nonspacing-marks (s)
                                         (ucs-normalize-NFC-string
  					(apply #'string (seq-remove #'nonspacing-mark-p
                                                                      (ucs-normalize-NFD-string s)))))
                 (cl-replace (title pair)
                             (replace-regexp-in-string (car pair) (cdr pair) title)))
        (let* ((pairs `(("[^[:alnum:][:digit:]]" . "-") ;; convert anything not alphanumeric
                        ("--*" . "-")                   ;; remove sequential underscores
                        ("^-" . "")                     ;; remove starting underscore
                        ("-$" . "")))                   ;; remove ending underscore
               (slug (-reduce-from #'cl-replace (strip-nonspacing-marks title) pairs)))
  	(downcase slug)))))
#+end_src

#+index: YASnippet!"Getting Started with YASnippet," InfoPonEmacs Journal (2023)

Through drafting [[https://emsenn.substack.com/p/unsettling-times][Unsettling Times]], I found myself struggling to accomplish the /typesetting/ I was hoping to, either with the export I plan(ned) to syndicate through /my Substack/, or with the Website I'm designing for uploading to emsenn.net. I'd been using /Org-transclusion/ to attempt to add the /definitions/ of /terms/ as /asides/ to my /Letters to the Web/, but was running into difficulties - I think I'm just not quite understanding the /use-cases/ for using /Org-transclusion/ properly. So, I'm going to switch back to what I used to do - using a named =definition= paragraph near the start of most of my record files, and then using /Org-inclusion/ to pull in that definition.

#+begin_aside
#+include: "~/org/enc/def/typesetting.org::definition"
#+include: "~/org/com/web/let/index.org::definition"
#+include: "~/org/enc/def/org-transclusion.org::definition"
#+include: "~/org/enc/def/definition.org::definition"
#+include: "~/org/enc/def/term.org::definition"
#+include: "~/org/enc/def/aside.org::definition"
#+include: "~/org/enc/def/use-case.org::definition"
#+include: "~/org/enc/def/org-inclusion.org::definition"
#+include: "~/org/enc/def/org-block.org::definition"
#+include: "~/org/enc/def/yasnippet.org::definition"
#+include: "~/org/pro/src/elisp/infoponemacs/infoponemacs.org::definition"
#+include: "~/org/enc/def/readme.org::definition"
#+end_aside

For example, to include the definition for /typesetting/, I can make an /Org-block/ for an /aside/, and in it, put =#+include: "~/org/def/typesetting.org::definition"=  and then whenever I export the file, it'll replace it with whatever is after =#+name: definition= in =~/org/def/typesetting.org=.

To get that into documents faster, I decided to add /YASnippet/ to /InfoPonEmacs/. YASnippet's documentation was pretty straightforward; it wasn't hard to figure out a =use-package= declaration that would work:

#+name: elisp-use-package-declaration-yasnippet
#+begin_src elisp
  (use-package
    yasnippet :straight t :ensure t
    :hook ((text-mode
  	  prog-mode
  	  conf-mode
  	  snippet-mode)
  	 . yas-minor-mode-on)
    :custom (yas-snippet-dir "~/org/sni"))
#+end_src

What was more confusing to me was the way that snippets would be stored. I think maybe the project's /README/ got pared down at some point, and the tutoria never got added to other documentation. So, I looked through a few tutorials online for help:

- [[https://arjanvandergaag.nl/blog/using-yasnippet-in-emacs.html][Arjan van der Gaag]] :: Good explanation of YASnippet parameterizing.
- [[https://howardism.org/Technical/Emacs/templates-tutorial.html][Howardism]] :: This pointed me to the command for inserting new snippets, =yas-new-snippet=

With =yas-new-snippet=, I was able to figure out that each snippet is stored in its own file, in a folder named for the mode in which it'll be active. So, in =~/org/snippets/org-mode/def=, I've now got:

#+begin_src org
  # -*- mode: snippet -*-
  # name: def
  # key: def
  # --
  ,#+include: "~/org/$1.org::definition"
#+end_src

Now, I can type "def", hit =TAB=, and my cursor will be put after =~/org/=, so I can type which specific record I wanna include the definition of.
