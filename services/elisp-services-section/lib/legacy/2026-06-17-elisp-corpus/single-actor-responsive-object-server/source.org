* Single Actor Responsive Object Server
The /single actor responsive object server/ (hereafter /SAROS/) is a server implemented in Elisp. Currently it serves HTML documents, which are generically called "objects." These objects are created using a combination of data serialized as /Elisp/ lists and Org-mode files.

In addition to requiring I believe Emacs version 24 or greater, these instructions require the following Emacs packages
- =web-server=, which provides functions for running the HTTP server and responding to requests.
- =mustache=, which provides functions for templating objects.
- =ht=, which provides easier ways to declare hash tables.

** Data
Your SAROS relies on at least having a configuration to look at, currently kept at =ems-saros-config=. The other kind of data are its templates - collections of /mustache/ templates that are filled in with data to make the rendered objects.
*** Config(uration)
This is the configuration for your SAROS, and has the information about the actor it's to represent.
#+begin_src elisp
(setq ems-saros-config
(ht ("preferred-name" "emsenn")
    ("proper-name" "emsenn")
    ("template-directory" "~/src/saros/mustache/")))
#+end_src
***** Variables
- =preferred-name= :: The name you would prefer to be called in general company.
- =proper-name= :: The name you'd prefer to be used in official contexts.
- =template-directory= :: The directory where SAROS will look for mustache templates.

#+begin_src elisp
    (defun ems-saros-start (&optional config)
      "This function starts your SAROS."
      (if (ems-saros-validate-config (if config config ems-saros-config))
	  (ws-start
	   (lambda (request)
	     (with-slots (process headers) request
	       (let ((path (substring (cdr (assoc :GET headers)) 1)))
		 (if (eq path "")
		 (let ((template (with-te)
			   (context ems-saros-config))
		       (ws-response-header process 200 '("Content-type" . "text/html"))
		       (process-send-string process
					    (mustache-render template context)))
  ))))
	   9000)))
#+end_src
