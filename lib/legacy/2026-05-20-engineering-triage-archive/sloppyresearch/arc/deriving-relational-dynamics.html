Formalizing "Deriving Relational Dynamics" in Category-Theoretic Terms

A simplicial-set representation K : Δᵒᵖ → Set

1. Ambient category and notation

  • Work in sSet = Fun(Δᵒᵖ, Set)
  • Δⁿ : standard n-simplex
  • ∂Δⁿ : its boundary
  • Λⁿₖ : k-th horn
  • Nondegenerate n-simplex of X ∈ sSet = monomorphism Δⁿ ↪ X

  • Adjoining an n-simplex along a boundary is the pushout diagram: 

    \begin{tikzcd}
\partial\Delta^n \ar[r] \ar[d, hook] & X \ar[d] \\
\Delta^n \ar[r] & X \cup_{\partial\Delta^n}\Delta^n
\end{tikzcd}

2. Base object K(0) ("K₀")

Define K(0) as the simplicial set freely generated by one nondegenerate 2-simplex σ : Δ² ↪ K(0) with vertices {δ, ¬, =}.

Pushout description: 

\begin{tikzcd}
\partial\Delta^2 \ar[r] \ar[d, hook] & \Delta^0\sqcup \Delta^0\sqcup \Delta^0 \ar[d] \\
\Delta^2 \ar[r, hook] & K^{(0)}
\end{tikzcd}

3. Adding relation r and closing to a 3-simplex (K(1))

Adjoin new vertex r and one nondegenerate 3-simplex τ : Δ³ ↪ K(1) with vertices δ, ¬, =, r.

Pushout: 

\begin{tikzcd}
\partial\Delta^3 \ar[r] \ar[d, hook] & K^{(0)}\sqcup \Delta^0_r \ar[d] \\
\Delta^3 \ar[r, hook] & K^{(1)} := K^{(0)}\cup_{\partial\Delta^3}\Delta^3
\end{tikzcd}

4. Reflexive triad (a, ρ, f) as 3-simplex (K(2))

Add vertices a, ρ, f and attach a nondegenerate 3-simplex κ : Δ³ ↪ K(2).

Pushout: 

K^{(2)} := K^{(1)} ∪_{∂Δ³→K^{(1)}∪Δ⁰_a∪Δ⁰_ρ∪Δ⁰_f} Δ³

Interpretation: faces of κ encode partial compositions among (a, ρ, f).

5. Second-order morphism r′ as a 4-simplex (K(3))

Encode higher relation (a,ρ) ↦ (ρ,f) by adjoining one nondegenerate 4-simplex θ : Δ⁴ ↪ K(3).

Faces of θ represent the participating 3-simplices.

6. Boundary formation (K(4))

Boundary operator on chains: 

\partial_n : C_n(K^{(3)};ℤ) → C_{n-1}(K^{(3)};ℤ)

Generated simplicially by face maps dᵢ of K(3).

Represent the triplet (e, n, b) as a new simplex (2- or 3-simplex β) attached via a boundary pushout. The boundary subcomplex ∂K₃ is the image of sk₂(Δ³) ↪ Δ³ ↪ K(1) ⊂ K(4).

7. Boundary reflexivity rb : ∂K₃ → ∂K₃ (K(5))

An endomorphism of a subcomplex i : B ↪ K(4) is a simplicial map rb : B → B.

Internalize it by adding a mapping cylinder: 

B → Cyl(r_b) → B

Attach Cyl(rb) along B: 

K^{(5)} := K^{(4)} ∪_{B→Cyl(r_b)} Cyl(r_b)

8. Multiplicity and differentiation (K(6))

Let 𝕀 be a small index category with objects i, morphisms δᵢⱼ : K⁵ᵢ → K⁵ⱼ, δᵢᵢ = id. Define a functor D : 𝕀 → sSet, i ↦ K⁵ᵢ.

Multiplicity complex: 

K^{(6)} := colim_{i∈𝕀} K^{(5)}_i

9. Field integration (K(7))

Inter-unit relations φᵢⱼ : K⁵ᵢ ⇄ K⁵ⱼ extend 𝕀 to a span-enriched diagram 𝔇 in sSet.

Field complex and integration map: 

F := colim 𝔇
Φ : ⨿_i K^{(5)}_i → F
K^{(7)} := F

10. Meta-boundary, folding, and extension (K(8), K(9))

Meta-boundary: monomorphism ιₘ : Bₘ ↪ F.

Meta-reflexivity and meta-transcendence: 

Rₘ : Bₘ → F
Tₘ : Bₘ → F′

Pushout forming meta-extension: 

\begin{tikzcd}
B_m \ar[r,"T_m"] \ar[d,"ι_m"'] & F' \ar[d] \\
F \ar[r] & F ∪_{B_m} F'
\end{tikzcd}

Define K(9) := F ∪Bₘ F′.

Iterating (Tₘ ∘ Rₘ) gives chain F ⊂ F′ ⊂ F″ ⊂ ⋯.

11. Inductive system and colimit K_∞

Filtered diagram: 

K^{(0)} → K^{(1)} → K^{(2)} → ⋯

Each iₙ is a monomorphism from corresponding pushout.

Colimit in sSet: 

K_∞ := colim_{n∈ℕ} K^{(n)}

Levelwise: 

K_∞[m] = colim_n K^{(n)}[m]

Face and degeneracy maps inherited naturally from Δ.

12. Optional fibrancy (inner horn filling)

To ensure higher-order closure, attach fillers for all inner horns Λⁿₖ ↪ Δⁿ.

This produces a Kan complex (fibrant object) K(ω) and a canonical map K(n) → K(ω).

13. Chain-level boundary (homology tie-in)

Normalized chain complex: 

N_*(K_∞;ℤ),  ∂ₙ = Σ_{i=0}^n (-1)^i d_i : N_n → N_{n-1}

Encodes the "boundary formation" operator ∂.

14. Compact definition

A relational dynamics object is a simplicial set K : Δᵒᵖ → Set presented by a filtered diagram (K(n), iₙ) in sSet such that:

  1. K(0) is freely generated by one nondegenerate 2-simplex with vertices {δ, ¬, =}.
  2. For each n ≥ 0, K(n+1) is obtained from K(n) by pushouts of ∂Δᵐ ↪ Δᵐ (attaching simplices for r, a, ρ, f, r′, …) and possibly horn fillers Λᵐₖ ↪ Δᵐ for stability.
  3. K := colimₙ K(n) (i.e. K_∞).

This functor K : Δᵒᵖ → Set has face/degeneracy maps induced naturally from Δ, forming a coherent simplicial hierarchy representing the formal derivation of existence as relational dynamics.
