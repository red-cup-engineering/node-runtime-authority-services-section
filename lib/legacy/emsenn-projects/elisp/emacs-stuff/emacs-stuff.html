Introduction

This collection of Elisp contains all the stuff I've written to make my life using Emacs easier. Emacs is the text-editor that I do almost all of my computer work through.

Emacs Stuff

Overview

I use Emacs as my primary interface for my computer. There's a common joke, "Emacs is a wonderful operating system - and an awful text-editor."

I'm inclined, in many ways, to agree. I have found it a wonderful way of operating a computer system, and incredibly lacklustre as a text-editor. I need to be clear, here, though: the only reason I think Emacs is a bad text-editor is because, due to its easily-extensible nature, it is easy to want to make it better, and better, and better. A default Emacs client is the best text-editor there is - but it's also, really bad.

This file contains the things I've made to make my personal Emacs client, as much as I can, "good."

[2019-07-04 Thu] I'm new to learning Emacs, and this collection of configuration is newly-collected from my disparate dabbling in it. There may be typos and non-functional code, and most things are without sufficient explanation.

Theming

Slow Theming

It's been a bit since I copy-pasted this from some tutorial or another, but if I remember correctly, this says "don't load any initial theme, wait until one is specified." This keeps Emacs from flickering about a bunch as it starts up. 

(defadvice load-theme (before theme-dont-propagate activate)
  (mapc #'disable-theme custom-enabled-themes))

Oxfordize List

(defun ems-oxfordize-list (list)
  (let ((len (length list)))
    (cond ((= len 1)
           (car list))
          ((= len 2)
           (concat (car list) " and " (cadr list)))
          (t
           (setcar (last list)
                   (concat "and " (car (last list))))
           (string-join list ", ")))))

Slug-Case String

The following Elisp function takes a string and returns it slug-cased. 

(defun ems-slugify (str)
  (replace-regexp-in-string
   " " "-"
   (replace-regexp-in-string
    "[^[:alnum:]()]" " "
    (replace-regexp-in-string
     "\\." ""
     (replace-regexp-in-string
      "&" " and "
      (downcase str))))))
