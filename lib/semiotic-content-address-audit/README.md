# Semiotic content address source audit — Computer Code library

This is the existing source-analysis scanner relocated from the former
Computer Content Address Engineering section. It classifies *candidates* of
divergent internal identity production and reports precise source lines.
Hashing for signatures, Git carrier OIDs, checksums, and foreign protocols
is not automatically a violation.

Run `npm run audit:content-addressing -- ../other-project` or import the
source's `./semiotic-content-address-audit` export from Computer Code.
Canonical carrier identity remains under Computer Data
`lib/semiotic-content-address`; NI syntax remains under URI Services.
