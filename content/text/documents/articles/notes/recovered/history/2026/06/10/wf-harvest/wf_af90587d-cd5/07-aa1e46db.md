# Boundary design for @emsenn/meme-topology — extension-without-forking (mathematician's brief)

Ground rule for the whole design: the library is one inductive construction, and its module graph is a presentation of a category — objects are carrier vocabularies, arrows are "generated-from." The boundary must expose that presentation at three tiers: a **keystone tier** (consume the construction), a **theory tier** (extend the construction along its existing universal properties), and an **interior** (proofs of the construction, not API). Extension never requires forking iff every parametric object the construction is instantiated *at* — the lattice, the order, the generator, the endomorphism, the reading — is exported with a lawfulness judgment that an extender can discharge in their own package.

---

## 1. Entrypoint structure: curated root + complete subpath lattice (not either/or)

**Argument.** The tests treat the barrel as the boundary (all 3 suites import only `./index.mjs`), so the barrel is the de-facto spec and must survive — but today it star-exports ~850 flat names (`dual`, `rank`, `present`, `judgment`, `divide`...), which is unusable as a shared vocabulary for 75 packages and guarantees collisions. Conversely, pure subpaths without a curated root would force every consumer to learn the 24-module decomposition before writing `induce`. And the current 13/24 subpath map is the worst of both: it asserts a boundary the barrel doesn't enforce, and the 9 missing subpaths are exactly the newest modules — the map encodes history, not structure.

**Design.**

- `src/index.mts` becomes curated, two-layer:
  - **Flat keystone exports** (the only unqualified names): `induce`, `extend` (new, §4), `MemeTopologyCarrier`, `Attestation` (née `Witness`), `attest`, `readCharge`, `fixedPointReadings`, `MemeTopologyFixedPointReading(s)`, `chargeValue`, `charge`, `ChargeValueName`, the four extrema accessors, `mark`/`token`/`claim`/`cell`/`specializationMorphism`, and the judgment-union types consumers match on.
  - **Namespace re-exports mirroring the generation paths**: `export * as charge`, `export * as fiber`, `export * as ordinal`, `export * as sheaf`, `export * as settling`, `export * as firing`, `export * as cohomology`, `export * as theory`, `export * as relation`, `export * as exact`, `export * as spectral`, `export * as substitution`, `export * as reading`. Import statements then *are* morphism paths: `import { closureProcess } from "@emsenn/meme-topology"` becomes `ordinal.closureProcess` — the namespace is the categorical address.
- **Every public module gets a subpath** in package.json; subpath names mirror the dot-path morphology, not file history: `./predication/fiber`, `./predication/valuation/fixed-point`, `./predication/valuation/fixed-point/gap`, `./ordinal-closure`, `./reading`, etc. A module either has a subpath + docs (public) or lives under `src/internal/` with no subpath and no index export (interior). No third state.
- **Module category presented explicitly**: the README and a generated `docs/module-category.md` carry the generation DAG —
  `utterance → predication → {fiber, theory} ; predication.fiber → valuation → {sheaf, consistency} → closure → fixedPoint → {gap, reading} ; bilattice.charge → {linearLogic, relation, fiber-orders} ; ordinal.closure ⇒ (parametrizes) valuation.closure ; exactNumber ⇒ {cohomology, spectral, substitution} ; everything → meme-topology (the colimit, induce)`.
  Subpath names, namespace names, and kind prefixes are the same strings. An extender locates their extension by finding its position in this diagram, not by grepping.

## 2. Public vocabulary by category (with renames)

Naming rules adopted wholesale from the conformance audit: **K1** atoms are camelCase single words (kind strings lose compound-noun dashes); **K3** judgment halves attach as `:witness` / `-obstruction`; **K4** every witness|obstruction union is `<Subject>Judgment`; **K5** `Carrier` name ⟺ `.carrier` kind atom; **K6** `Witness` reserved for judgment-affirmatives; **K7** no exported boolean judgments (sole declared exemption: exact-number arithmetic comparators). Function-level rule: judgment functions are the bare property noun — no `verify`/`check`/`is...Holds` prefixes; multi-way classifications alone keep `classify*`.

### A. Syntax — the free category on utterances (`utterance`, `predication`)
`mark`, `token`, `claim` (factories; **`Mark`/`Token`/`Claim` classes become interior** — interfaces exported, classes not: the only classes in a frozen-POJO algebra), `utterance`, `articulate`, `cell`, `specializationMorphism`, `predicationCarrier`, `predicate`, `cohere`, `closeSpecialization`, `entitySet`/`predicateSet`/`cellSet`, identity judgments `markIdentity` … `cellIdentity` (the coincidence module folds into these; see §3). Renames: `unrelatedPairs` gets a named `UnrelatedPairsCarrier`; `PredicationWitness` → `PredicationDatum`.

### B. The bilattice object (`charge`, `linearLogic`)
`chargeValue`, `charge` (type `Charge` → `ChargeCarrier`), `chargeValues`, `asChargeValue`/`chargeValueName` (the sanctioned string boundary), value-level algebra `joinKnowledgeValue`/`meetKnowledgeValue`/`joinTruthValue`/`meetTruthValue`/`negateValue`/`conflateValue`, carrier-level `negate`/`conflate`/joins/meets, **gauge group** `gauge`/`fixedSet`/`GaugeElementName` (promoted to first-class — it is the order-independence machinery, §4.3), `firingPatternSelfDuality`, full linear-logic module (`linearFusionValue`, `linearResiduumValue`, `linearNegationValue`, `linearParValue`, `chargeConsistency`, `truthOrderResiduation`, `consistentChargeValues`). Renames: `leqKnowledge`/`leqTruth` → `knowledgeLeq`/`truthLeq` returning `OrderLeqJudgment` carriers (witness carries the join computation; obstruction carries the counterexample) — these are *theorem statements*, not predicates. `witnessedPotential` → `attestedPotential`. The three duplicate `"knowledge"|"truth"` aliases collapse to one `OrderName` exported here.

### C. The fibration — indexed category over the base (`fiber`)
`Attestation` (née `Witness` — **mandatory rename**: it is the parameter type of `induce` and is not a judgment witness), `attest` (née `witnessCarrier`), `Meme`, `meme`, `FiberAlgebra`, `Valuation`, `FiberCarrier`, `Order`/`knowledgeOrder`/`truthOrder` (the two orders as exported values — extension point), `PredicateFiber`, `predicateFiber`, `fiberFromAlgebra`, `FiberGenerator` + `converse`/`subjectProjection`/`objectProjection`/`specialization` (extension point, §4.4), `posit`, `composeFibers`, `chargeAt`, `predicationFiberLinearFusion`/`Residuum`. Renames: `generatorPreservesLinearFusion`/`...Residuum`/`generatorSatisfiesLinearFusionFrobenius` + `leqTruthPredicateFiber` are **carrier-ized into one judgment** `generatorLawfulness` (§4.4) — they are the named theorems of the fibration and currently return bare booleans, the worst discipline breach on the extension surface. `GeneratorKind` values lose dashes: `"subjectProjection"` etc.

### D. The closure engine — ordinal-indexed iteration (`ordinal`)
**This whole module is theory-tier, not interior** — it is the engine every new dynamic plugs into: `Ordinal` (zero/successor/limit), `zeroOrdinal`/`successorOrdinal`/`limitOrdinal`/`finiteOrdinal`/`omegaOrdinal` family, `finiteOrdinalReading`, `Lattice<T>` (the parametric object, extension point), `ClosureProcessCarrier`, `closureProcess`, `closeOrdinalProcess`, `closureStabilizationSearchHorizon` (a *parameter*, hence public), `ClosureRegime` vocabulary, `leastFixedPoint`. Interior: `closureApproximant`, `closureOrbitOfProcess`, `stabilizingSup`, `closureSearchBlock(s)`, `showOrdinal`.

### E. Valuation dynamics — sheaf, consistency, closure, fixed points, gap (`sheaf`, `closure`, `fixedPoint`, `gap`)
`presheaf`, `presheafFromValuation`, `sheafFromValuation`, `commutate`; modal operators `raiseKnowledge`/`lowerKnowledge`/`raiseTruth`/`lowerTruth`/`possibilize*`/`necessitate*` (**keep public** — downstream program-processor demands them by name, and they are the exemplar endomorphisms for §4.5); `knowledgeValuationClosure`/`truthValuationClosure`, `knowledgeClosureTrace`, `knowledgeClosureSheaf`, `knowledgeValuationClosureLattice` (extension point — promoted from untested limbo); `fixedPoints`, the four extrema `knowledgeLeastFixedPoint` etc., `fixedPointOrderName`/`fixedPointBoundName`, `fixedPointKnowledgeGap`/`fixedPointTruthGap`, `FixedPointGapCarrier` and its reading types; `valuationConsistency`. ### F. Settling, firing, cohomology (`settling`, `firing`, `cohomology`)
`settling`, `classifySettling`, `SettlingCarrier`, cofinality constructors, `settlingDepth`, `settlingIncrements`/`settlingFirings`/`settlingLimitStages`/`nonScottSettlingFirings`, `settlingFirstCohomology`, `settlingClosureInvariant`, `gradedGap`; `classifyFiring`, `classifyFiringOrbit`, `firingGrade(s)`, `firingFirstCohomology`, `firingGradeCohomology`, `firingIndependence`, `valuedFiringsFromSettling`; `cohomology`, `cohomologyOfCells`, `cohomologyOfValuation`, `cohomologyLaplacian(OfCells)`, `rankIdentity`/`rankVanishing`/`rankComparison`. ### H. Arithmetic and spectra (`exact`, `spectral`, `substitution`)
Full nat/int/rat/matrix algebra, `polyFromInts` family, `resultant`, `mahlerMeasure`, `rootLocation`, `pisotRoot` (née `pisotRootJudgment`), `dominantRootConvergence`; substitution `substitute`/`iterateSubstitution`/`fixedPointClosure`/`abelianize`/`perronConvergent`/`primitivity` (née `primitiveMatrixJudgment`)/`matrixPisot` (née `matrixPisotJudgment`)/`substitutionRuleSelfDual`/`colimStructure`. The unprefixed generics (`divide`, `sign`, `gcd`, `members`, `successor`, `mobius`, `rank`...) survive **only inside the `exact.`/`spectral.` namespaces**, never flat.

### I. Readings (`reading`)
`fixedPointReading`, `fixedPointReadings`, `readCharge`, `informationOfSheaf`, `MemeTopologyInformation` — plus the reading contract of §4.2. Renames: kind `meme-topology.fixed-point-reading` → `meme-topology.fixedPointReading` per K1; `RelationReadAbsence`/`RelationMatrixEntryAbsence` → `...Obstruction` (one negative vocabulary; `RootLocationDegeneracy` likewise becomes an obstruction with a `reason` field).

## 3. What becomes interior, and why

Principle: **a symbol is interior iff it is an intermediate step of a public construction whose output is already carried by the public carrier.** Tests confirm the partition: every item below is either never imported by any test or actively routed around.

- **All of `carrier-coincidence`**: the eight coincidence families are wrappers over identity judgments (fold the carrier-returning forms into their subject modules as `markCoincidence` etc. *if* kept at all); the nine `*Holds` booleans are **deleted** — math.test.mts:272-278 reimplements them locally from carriers, the clearest possible evidence the spec rejects them.
- **Sub-carrier assembly constructors**: the six in `predication-valuation-consistency` (:92-156), six in `fixed-point-gap` (:112-180), five `memeTopologyInformation*` builders — their outputs are fields of the parent carriers; exporting them freezes interior proof steps as API.
- **Settling stage builders** (`settlingInitialStageOrdinal` … `settlingLimitStageInput`, 13 exports): these are `settling()`'s induction steps. *Exception*: the `*Input` constructors stay public because they are the only way to author a transfinite settling by hand (tests do this) — keep `settlingInitialStageInput`/`settlingSuccessorStageInput`/`settlingLimitStageInput` + ordinal constructors, internalize the shape/designated-cells builders.
- **Firing nullary factories** (11 frozen-singleton constructors, `predication-firing.mts:270-312`): enum values reachable only as outputs; consumers match on `.kind`.
- **Ordinal search plumbing** (§2D list) and `bilattice-charge`'s validation battery (`isChargeSideName`, `asChargeValueName`...) except the two string-boundary functions; `ChargePair`, `compareKnowledge`, `aggregate`, `present`, `valueOf` (replaced by a named accessor on the reading surface).
- **exact-number set-encoding internals** (`membershipPredicate`, `sameMembershipPredicate`, `members`, `isMember`, `asExtension`, `extensionOf`): the von Neumann encoding is a representation theorem, not an interface — though `asExtension`'s bridge to `bilattice-relation` deserves one documented public theorem-function if anything downstream uses it.
- **`typed-theory` plumbing**: `cellOf`, the four nullary morphism constructors, `inferenceTrace`.
- **All bare-boolean `same*` equalities** (`sameMeme`, `sameValuation`, `sameSettlingStageOrdinal`, `sameSubstitutionSymbol`, `sameCharge`): interior; public equality is the identity-judgment family.

What must **not** be internalized despite app-tier irrelevance — the extension tier: `Lattice<T>`, `closureProcess`, `Order`, `FiberGenerator`, `gauge`/`fixedSet`, `InferenceRule`/`InferenceMorphism`, `knowledgeValuationClosureLattice`, the modal operators, `predicateFiber`, `theoryOfBase`. The surface survey marks several of these "untested leaked machinery"; for this persona they are precisely the objects the construction is parametric in. The fix is tests + docs, not demotion.

## 4. What is MISSING for extension (signatures)

**4.1 Charge-polar attestation — the bilattice is currently unreachable from the keystone.** `induce` seeds everything at `attestedPotential` (meme-topology.mts:42), so every induced topology lives in the lower knowledge-cone: `stable` and `active` cannot arise from admission, meaning the library's central theorem (stable = held contradiction) is unexercisable through its own colimit. Required:

```ts
export function attest(
  predication: PredicationDatum,
  seed?: ChargeValue,            // default attestedPotential; "active" = denial, "stable" = held both-ways
  payload?: unknown,             // opaque provenance; carried, never inspected, monotone
): Attestation;
```

**4.2 The reading contract — lawful extension point #1.** A reading is a morphism out of an extremum. Today `fixedPointReading` is one hardcoded instance; extenders need the shape plus the proof obligation:

```ts
export interface ReadingDefinition<C> {
  readonly kind: "meme-topology.readingDefinition";
  readonly name: string;                                   // must pass kindMorphology (4.6)
  readonly of: (extremum: FixedPointExtremum) => C;        // pure, must freeze
}

export function readingMonotonicity<C>(
  definition: ReadingDefinition<C>,
  chain: readonly (readonly Attestation[])[],              // W₀ ⊆ W₁ ⊆ … finite probe chain
  leq: (before: C, after: C) => OrderLeqJudgment,          // order on the reading's codomain
): ReadingMonotonicityJudgment<C>;
// witness: the monotone orbit ⟨R(induce(Wᵢ))⟩ with per-step leq witnesses
// obstruction: the failing pair (Wᵢ, Wᵢ₊₁, R(Wᵢ), R(Wᵢ₊₁)) and its leq obstruction
```

This is how a new reading *proves* it preserves evidence monotonicity: monotone evidence in (the chain), monotone reading out, witnessed, exact, frozen.

**4.3 Order-independence via gauge equivariance — lawful extension point #2.** The two orders stay independent iff new operations are equivariant under the gauge element fixing the other order (negation is the truth-flip fixing knowledge; conflation the knowledge-flip fixing truth). The gauge group already exists (`bilattice-charge.mts:265-278`); what's missing is the judgment:

```ts
export function gaugeEquivariance(
  operation: (value: ChargeValue) => ChargeValue,
  element: GaugeElementName,
): GaugeEquivarianceJudgment;
// witness iff operation ∘ g = g ∘ operation on all four values (exact 4-point check);
// obstruction carries the value where the square fails to commute.
```

A new reading or endomorphism ships `gaugeEquivariance(op, "negation")` (knowledge-order-respecting) or `"conflation"` (truth-order-respecting) in its own proof carrier. This makes "the two orders stay independent" a checkable theorem instead of a README sentence.

**4.4 Open generator admission — new domain topologies.** `GeneratorKind` is a closed 4-string union (`predication-fiber.mts:129`) and `transportValuationAlongPredicationGenerators` is hardwired to it: a new base-category morphism today requires a fork. Required:

```ts
export type GeneratorKind =
  | "specialization" | "converse" | "subjectProjection" | "objectProjection"
  | `_${string}`;                                          // the kind-grammar escape, for extension

export function fiberGenerator(spec: {
  readonly name: GeneratorKind;
  readonly domain: readonly PredicateFiberCell[];
  readonly codomain: readonly PredicateFiberCell[];
  readonly pullback: (fiber: PredicateFiber) => PredicateFiber;
}): FiberGenerator;                                        // exists/forall derived as the order-adjoints of pullback

export function generatorLawfulness(
  generator: FiberGenerator,
  probes: readonly PredicateFiber[],
): GeneratorLawfulnessJudgment;
// carrier-izes the three existing boolean laws (fusion preservation, residuum preservation,
// Frobenius) plus adjointness exists ⊣ pullback ⊣ forall, with per-law sub-witnesses.
```

New domain topologies then enter exactly as the theory intends: `specializationMorphism` witnesses for the base poset (already public, already transitively closed by `closeSpecialization`), plus lawful custom generators for the fibered structure.

**4.5 Custom closure dynamics — new modal operators.** The engine exists (`closureProcess` over `Lattice<T>`); the valuation-level instantiation is private wiring. Required:

```ts
export function closeValuation(
  p: PresheafCarrier,
  endomorphism: (valuation: Valuation) => Valuation,
  order: OrderName,
  horizon?: ClosureStabilizationSearchHorizon,
): PredicationValuationClosureCarrier;                     // generalizes knowledgeValuationClosure

export function endomorphismMonotonicity<T>(
  lattice: Lattice<T>,
  endomorphism: (value: T) => T,
  probes: readonly (readonly [T, T])[],                    // pairs with probe[0] ⊑ probe[1]
): EndomorphismMonotonicityJudgment<T>;
```

Per house rules, unlawful endomorphisms are not rejected by throwing — divergence is already data (`aperiodic` regime, stabilization obstruction); the lawfulness judgment is the extender's published proof, not a gate.

**4.6 Kind-grammar judgment — new judgment forms.** Extenders mint new kinds; nothing checks them. The grammar is mechanical, so judge it:

```ts
export function kindMorphology(kind: string): KindMorphologyJudgment;
// witness: parsed path — atoms (single camelCase words) and operators
//   (generatedFrom ".", witnesses ":", obstructs "-", escape "_") in sequence;
// obstruction: the offending token and position.
```

This single function lets every downstream package property-test its kinds against Three Dots and a Dash, and is the enforcement mechanism for the K1–K3 migration itself.

**4.7 Monotone extension of the colimit.**

```ts
export function extend(carrier: MemeTopologyCarrier, delta: readonly Attestation[]): MemeTopologyCarrier;
// sound because evidence is monotone: re-close from the previous fixed point seeded with delta

export function extensionMonotonicity(
  before: MemeTopologyCarrier,
  after: MemeTopologyCarrier,
): ExtensionMonotonicityJudgment;
// witness: pointwise knowledgeLeq between knowledgeLeast readings over shared cells
```

`extensionMonotonicity` is the theorem a new domain topology cites to prove its admission lost no evidence — and it doubles as the daemon-tier incremental-settling primitive the downstream survey ranks #3.

## 5. Consumer contract (README head)

> Every judgment in this library returns a frozen witness-or-obstruction carrier — never a bare boolean, and never an exception for a domain outcome (throws mean malformed input, nothing else). Evidence is monotone: adding attestations can only move charges up the knowledge order, and `stable` is a held contradiction — a result, never an error. The knowledge order and the truth order are independent; never mix their joins, and prove any new operation respects them via `gaugeEquivariance`. All arithmetic is exact (`exact.*` carriers, never floats), and every `kind` string parses under Three Dots and a Dash (`.` generated-from, `:` witnesses, `-` obstructs, `_` escape) — check yours with `kindMorphology`. Consume through `induce`/`extend` and the readings; extend through the published parametric objects (`Lattice`, `Order`, `FiberGenerator`, `ReadingDefinition`, `InferenceRule`) by shipping their lawfulness judgments in your own proof carrier — if you are reaching past a subpath into `internal/`, you are forking, not extending.
