## 1. The daemon — `services/meme-topology-daemon`

### 1.1 Process model

One Node process, **single writer per address-space root**, three concurrent planes sharing no mutable state except the standing carrier reference:

- **Admission plane** — receives witness batches (HTTP, conduits), gates provenance, appends to logs. Never blocked by settling. Cheap by construction (appends only).
- **Settling plane** — one serialized fiber. The ordinal advance is a critical section; there is never more than one settle in flight. Overlapping triggers collapse to the standing result (newswire's reentrancy guard, kept).
- **Serving plane** — read-only sections over the last completed carrier. Never touches the log write path.

**The log IS the state.** The standing carrier is a cache of `fold(log)`. Restart = re-fold: replay the admitted attestation logs through `induce`/`resume`, verify against the last checkpoint, resume ticking. The daemon holds no truth that is not on disk; `kill -9` at any instant loses at most un-fsynced receipts, never world coherence.

Single-writer enforcement: a lock file at `<root>/daemon/daemon.lock` holding a reference to the boot witness. A second daemon on the same root refuses to start (or starts in explicit `--read-only` section-serving mode). Both the lock acquisition and the refusal are witnessed.

### 1.2 Persistence layout (meme-topology-addressing terms = paths, posix-holography flatfile contract)

```
<root>/
  daemon/daemon.jsonl                    self-trace: boots, ticks, errors, mounts,
                                         quarantines, checkpoint events
  ingress/<conduit-term>/<leaf>.jsonl    raw receipts, pre-gate (even rejection is evidence)
  witnesses/<subject-term...>/<leaf>.jsonl   admitted attestations, per-subject (TTAM)
  tx/tx.jsonl                            transaction records closing admitted batches
  quarantine/quarantine.jsonl            held-inert records, with reasons as evidence
  mounts/<mount-term>/manifest.json      mount manifests (witnessed on registration)
  checkpoints/<ordinal-segment>.json     carrier-reading caches, each carrying
                                         {sourceCursor, sourceDigest} of the log
                                         prefix it was folded from
```

Append discipline: posix-holography flatfile contract wholesale (canonical bytes, O_APPEND single-line atomicity, fsync-before-resolve, torn-final-line tolerance, ENOENT = `[]`, no overwrite API exists). **Added on top: transactional batches.** A batch of attestation rows is admitted iff a single `tx` record naming the canonical ids of all rows exists in `tx/tx.jsonl`. Replay treats rows without a closing tx as torn and re-processes from the ingress receipt. This closes the flatfile's single-line-only atomicity gap without introducing any overwrite.

Checkpoints are Way-1-compliant caches: a checkpoint that doesn't hash-match its log prefix is discarded (and the discard witnessed), then full refold. Compaction/truncation of logs is **forbidden** (forgetting has a Landauer price, never a default); the memory/disk lever is sharding (below), not deletion.

### 1.3 Admission path (no witness, no world)

1. **Receive** — bytes arrive (POST `/witnesses` or a conduit). The mount's declared codec decodes to attestation inputs and computes **residue** (what the decode killed). The raw receipt + residue is appended to the ingress log *before* any judgment. Malformed-beyond-residue shapes are the only 4xx case (exceptions are for malformed shapes only).
2. **Gate** — provenance must resolve: the provenance term must reference a registered principal/conduit holding a capability grant over the addressed namespace (capability-gated resolve, posix-holography `guardAccess` pattern, but checking the causal path, not just field presence — explicitly rejecting memetics' carried-but-never-checked witness). Fail → append to quarantine log with reason, witness the quarantine in the self-trace, return `202 {status:"quarantined", id}`. Quarantine is **held inert, not dropped**: a later `POST /quarantine/{id}/provenance` supplies provenance evidence and the item is re-judged — admission of provenance is itself evidence.
3. **Admit** — batch-append attestation rows to per-subject witness logs, close with one tx record, fsync, return `202 {status:"admitted", tx}`, enqueue the tx on the pending queue for the settling plane.

Identity is canonical content (`termKey` over the row), so duplicate admission is a G-Set no-op — replays and at-least-once conduits are safe by construction.

### 1.4 Settling loop (a tick is a witness-driven ordinal advance)

There is **no interval engine**. The settling fiber wakes only when the pending queue is non-empty (or on explicit `POST /ticks`, where the POST itself is the triggering witness). A timer, if a mount declares one, is just a *conduit* that emits witnesses ("poll of X observed; wall-clock reading T as payload") which are admitted like any other evidence and thereby cause ticks.

One tick:

1. Drain **all** pending txs into one delta (coalescing — this is the natural backpressure valve: lag automatically produces bigger, fewer folds).
2. Advance: `resume(carrier, delta, fuel)` (lib seam, §3) — or `extend` full-recompute fallback until `resume` lands.
3. Advance the ordinal **as a term, not an integer**: `succ(τ)` per completed settle; the temporal-2-category reading means the tick record carries an `advance` term (admitting `α + β` composite advances later) — the linear counter is the degenerate shadow and never the wire shape.
4. Append a tick witness to the self-trace: ordinal term, txs folded, `SettlingClassification` (regime: finite | scott | transfinite | aperiodic), depth, fuel consumed, changed-cell digest, wall-clock duration *as witnessed payload*.
5. If fuel exhausted → record `regime:"partial-prefix"` honestly (settling-orbit's contract, kept verbatim), re-enqueue the continuation, keep serving the last *completed* fixed point with staleness declared. Partial settlement is never reported as final.

Errors inside a settle are caught, witnessed, and the offending batch is isolated by bisection (retry halves) into quarantine-with-reason; the remainder folds. A poison witness costs O(log n) retries, never a crash loop.

Quiescence is computed, not flagged: the daemon is quiescent when `settledHighWater == admittedHighWater` and the last settle reached a fixed point.

### 1.5 Backpressure and memory bounds

- **Admission never refuses evidence for being inconvenient.** It refuses only when it cannot *durably receive*: fsync failure or disk-full → `503` on `/witnesses` (serving continues read-only). Optional per-conduit token buckets are declared in mount manifests; bucket refusals are witnessed.
- **Lag** = admitted tx high-water − settled tx high-water, exposed in `/healthz`; threshold trips `status:"lagging"` (still 200 — sections are honest about staleness, see §1.6).
- **Memory**: the carrier is the cost center (lib is eager, frozen, O(n²) in places). Levers, in order: (a) incremental settling (lib demand); (b) **per-mount sharding** — each mount's namespace folds its own carrier (doctrinally clean: a mount is a *site* on the one engine, not a forked engine; cross-mount readings compose sections); (c) cold mounts can be **unmounted**: carrier dropped from RAM, log remains, remount = refold — eviction without erasure; (d) RSS/cell-count watermarks in healthz with `degraded` status. What is explicitly *not* a lever: log truncation.

### 1.6 Section serving

`GET /sections/...` is a window onto the last completed fold. A section request declares:

- a **reading**: `order` (knowledge | truth | mount-defined) × `bound` (least | greatest) — default knowledge-least;
- a **rendering**: `calm` or `audit` — the declared collapse choice. `audit` returns the full charge with the witness ids behind it; `calm` applies the mount's declared `RenderPolicy` and the response *names the policy it applied*. No boolean ever appears except behind a named calm policy; the carrier and default wire shape carry the general charge (`{algebra: "four", value: ...}` — FOUR as the named finite projection, so widening the algebra later is additive).

Every section response carries: the ordinal term it was taken at, `staleness` (admitted-but-unsettled tx count touching that namespace), and an `ETag` derived from the settling closure invariant / information signature — pollers get 304s for free. Before the first fold completes at boot, sections are `503 {status:"folding"}` (newswire's honest-503, kept). Contested cells are served calm or audit per the request — contradiction is a result, never an error status.

`GET /events` is an SSE feed of tick events only (`ordinal advanced, changed-cell digest D`); subscribers re-GET sections. The feed carries no charges, so it cannot become a side-channel that bypasses readings.

### 1.7 Mount model (one descent, many worlds)

A mount is vocabulary + readings + codecs + conduits + rendering policies + capability grants. **The manifest type has no field for settling logic** — Way 7 enforced by the shape:

```ts
interface MountManifest {
  readonly kind: "meme-topology.daemon.mount";
  readonly name: AddressTerm;                    // namespace root, term = path
  readonly vocabulary: VocabularyDecl;           // predicates/sorts as typed-theory terms
  readonly codecs: readonly CodecDecl[];         // site morphisms: decode -> {attestations, residue}, encode <- sections
  readonly readings: readonly ReadingDecl[];     // named projections over the carrier
  readonly conduits?: readonly ConduitDecl[];    // witness generators with their own provenance identity (timer, fs-watch, feed poll)
  readonly renderings: { readonly calm: RenderPolicy; readonly audit: RenderPolicy };
  readonly capabilities: readonly CapabilityGrant[];  // who may witness into this namespace
}
```

Mount/unmount are witnessed operations; the mount table is itself a reading over the self-trace (Way 9 — the daemon's configuration is cells in the substrate it settles). Conduit endpoint lists live in manifests as *admitted facts*, never source constants (rejecting swarm.mjs's hardwired `ENDPOINTS`).

### 1.8 Deployment, observability, rete-agentium-filum

- `services/meme-topology-daemon`, port **18794**, manifest key `"561:serve": { domain: "topology.561.group", kind: "proxy", port: 18794, sse: true, ws: false }`. Data root from config/env — **no baked absolute default** (rejecting memetics' `DEFAULT_TRACE_ROOT = "/memetics"`).
- CLI: `--once` (boot, fold, one tick, print snapshot JSON, exit) — the cron-able degenerate mode *and* the Wave 2 parity-oracle harness, since it makes the daemon a pure function over its logs. `--read-only` (serve sections, no admission). `--refold` (ignore checkpoints, full replay, report divergence). Injectable io/startServer for tests; `installGracefulShutdown` (newswire pattern: stop accepting, finish the in-flight tick, witness the shutdown, release the lock).
- `/healthz` (shape sketch):

```json
{ "kind": "meme-topology.daemon.health",
  "status": "folding|settling|quiescent|lagging|degraded",
  "ordinal": <ordinal term>, "advance": <last advance term>,
  "lag": { "admittedTx": n, "settledTx": m },
  "lastTick": { "regime": "finite|scott|transfinite|aperiodic|partial-prefix",
                "depth": d, "fuelUsed": f, "changedCellDigest": "...", "durationMs": t },
  "quarantine": { "held": k },
  "store": { "rootBytes": b, "lastFsyncError": null },
  "memory": { "rss": r, "mounts": [{ "name": "...", "cells": c, "witnesses": w }] } }
```

HTTP 200 whenever sections are being served honestly (including `lagging`); 503 only during boot fold or store failure. `/meme-topology-daemon.json` snapshot is a *reading over the self-trace* — run history, error history, and admission counts come from `daemon.jsonl`, not private fields, so they survive restart (rejecting newswire's `#runs`/`#lastError`).

**Failure modes, enumerated:** crash mid-batch → tx record absent → rows torn, re-admit from ingress receipt, idempotent via canonical ids. Crash mid-tick → no tick witness → boot folds to settled high-water, pending recomputed as admitted−settled, tick resumes; no torn world is representable. Checkpoint/log divergence → digest mismatch → checkpoint discarded (witnessed), full refold. Aperiodic/never-terminating settle → per-mount lag grows, regime surfaced, sections served at last fixed point with declared staleness — a reading, not a crash loop. Poison witness → bisected into quarantine with reason. Disk full → 503 admission, read-only serving. Double daemon → lock refusal, witnessed. Clock skew → cannot affect ordering by construction. Conduit flood → token bucket, refusals witnessed, receipts still cheap.

**Path to rete-agentium-filum (Wave 2, designed-for now):** newsroom's four hand-rolled settling functions become a `news` mount (vocabulary = claim/gate predicates; codec = existing claim-set JSON, residue-reporting); `ingestSources` adapters become conduits POSTing to `/witnesses`; newswire reads `GET /sections/news/...?render=calm` (websites need the shadow, fast) and its audit artifact maps to `render=audit`. lib/swarm's lib→service inversion into newswire is severed by replacing it with the section HTTP client; the daemon URL is a config cell, itself witnessed. Parity oracle = `--once` snapshots diffed against the live wire's public surfaces.

## 2. The workbench — `apps/meme-topology-workbench`

**Interaction model:** a REPL/notebook over the same primitives, verbs named for the gerunds, with two interchangeable backends behind one client interface — **in-process** (direct lib calls over an ephemeral or directory-backed root) and **remote** (the daemon's HTTP API). Same operations both ways; the workbench is therefore also the daemon's ops console.

Verbs: `articulate` (affirm/deny/specializes — provenance is mandatory and defaults to the workbench session identity, which is itself witnessed at session start); `settle` (tick; in-process this is `induce`/`resume` with visible fuel and regime); `read <reading> <cell...>`; `render calm|audit`; `diff <ordinal> <ordinal>` (changed cells between two ticks); `mount <manifest>`; `trace <subject>` (page the raw log); `quarantine list|supply-provenance`; `refold --verify` (operator verb: re-fold and compare against checkpoint/served sections).

**The session is a trace.** Every command is appended to a session log; replaying the log reproduces the session — a workbench session IS a program (programs are evidence). `export` emits the session's articulations as an admissible witness batch for a daemon, provenance intact. This makes the workbench the authoring path for domain bring-up: build a mount interactively, settle locally, export to production.

Operator mode: point the remote backend at a live daemon read-only — inspect lag, regimes per mount, quarantine queue, memory watermarks; run `refold --verify` against a copy of the root to audit a running instance without touching it. Web view (dev-only, port 18795) renders the audit reading of any section: charge lattice position, the witnesses behind it, the cohomology obstruction (H¹) for contested components — `coordinationFree` shown as a computed fact.

## 3. The seam — what lib/meme-topology must expose (gaps flagged)

What exists and is sufficient: `induce`/`extend`, `affirm`/`deny`/`specializes` (admission facade), `readCharge`, `settlingClosureEquivalence`, `classifySettling`, the exported closure-process seam (`predicationValuationClosureProcess`/`closePredicationValuationClosure`), and `meme-topology-addressing` for term↔path.

**Gaps the daemon needs (in priority order; #1–#3 block daemon-scale, #4–#6 block correctness of the wire):**

1. **Incremental settling with ordinal continuity** — `resume(carrier, delta, fuel?)` that (a) extends the `PredicationCarrier` base with new terms, (b) merges delta memes into the standing `Valuation` (today `composeFibers` rebuilds from a full meme list), and (c) **splices the new orbit onto the previous `SettlingCarrier` so stage ordinals continue instead of restarting at `zeroOrdinal()`** — today every `extend` is a full recompute and the carrier has no memory that it is stage n of a longer descent. Must return a regime-tagged result (`partial-prefix` honesty preserved). Already named in the Wave 1 journal; this design depends on it; daemon ships with `extend` fallback and an honest `degraded`-at-scale healthz until it lands.
2. **Cell-delta surface** — `cellDelta(before, after): CellChangeSet` (which cells changed charge, plus a stable digest). Today only the boolean-ish `settlingClosureEquivalence` exists. Needed for SSE digests, ETags, `diff`, and the Wave 2 parity oracle.
3. **Codecs** — the lib has zero serialization: `Mark` is a class that dies on JSON round-trip, `LimitOrdinal.fundamentalSequence` is a function. Needed (here or in a sibling `meme-topology-codecs-jsonl`): `encodeAttestation`/`decodeAttestation` (Cell/Mark term codec) and an **ordinal-term codec** — serialize ordinals as terms (`zero | succ(t) | limit(label, generatorTerm) | sum(a,b)`), i.e. the limit's *name*, never its function.
4. **General-charge wire shape** — wire/storage charge as `{ algebra: AddressTerm; value: unknown }` with `"four"` as the named finite projection, per the cosmogony doc's bedrock flag ("FOUR is forbidden in the core as *the* value"). Widening later must be additive.
5. **Canonical provenance terms** — `provenance?: unknown` is opaque and optional; the daemon's gate needs it `termKey`-compatible so quarantine/admission decisions are content-addressed. The *gate* stays in the daemon (lib rightly admits anything), but the lib should declare the canonical shape.
6. **Stable invariant export** — `settlingClosureInvariant`/information signature as a declared-stable string for ETags and quiescence checks.
7. (Flag, not blocker) O(n²) scans in information entries/gap pairing/cohomology indexing — per-mount sharding bounds n for Wave 1; incremental settling is the real fix.
8. **Site-morphism carrier** (already a Wave 1 lib demand) — `CodecDecl` in the mount manifest should be typed as the geometric-morphism pair (pullback/admission, pushforward/rendering) with loss as residue charge, so codec residue lands in the same algebra as everything else.

## 4. API sketches — the load-bearing operations

### TypeScript (daemon core; everything returns values, domain outcomes are never exceptions)

```ts
// 1. Admission — never throws on domain outcomes; malformed shape is the only throw
admit(input: WitnessBatchInput): Promise<AdmissionOutcome>;
type AdmissionOutcome =
  | { kind: "daemon.admission:tx";         tx: TxRecord; rows: readonly CanonicalId[] }
  | { kind: "daemon.admission-quarantine"; id: CanonicalId; reason: QuarantineReason };
interface WitnessBatchInput {
  readonly mount: AddressTerm;
  readonly provenance: ProvenanceTerm;          // mandatory at this boundary
  readonly body: Uint8Array | readonly AttestationWire[];  // codec-decoded if bytes
}

// 2. Tick — drains pending, advances the ordinal; reentrant calls collapse
tick(options?: { fuel?: Natural }): Promise<TickResult>;
interface TickResult {
  readonly kind: "daemon.tick";
  readonly ordinal: OrdinalTerm;                // term, not integer
  readonly advance: OrdinalTerm;                // admits α+β composite advances
  readonly folded: readonly TxId[];
  readonly classification: SettlingClassification;   // regime incl. "partial-prefix"
  readonly changed: CellChangeDigest;
}

// 3. Sections — observer-relative reading, declared rendering
section(query: SectionQuery): SectionResult | DaemonUnready;
interface SectionQuery {
  readonly target: AddressTerm | CellSelector;
  readonly reading: { order: AddressTerm; bound: "least" | "greatest" };  // orders are terms, not an enum
  readonly rendering: "audit" | { calm: PolicyName };
}
interface SectionResult {
  readonly kind: "daemon.section";
  readonly ordinal: OrdinalTerm;
  readonly staleness: { pendingTx: Natural };
  readonly charge: WireCharge;                  // { algebra: AddressTerm; value: unknown }
  readonly witnesses?: readonly CanonicalId[];  // audit rendering only
  readonly etag: string;                        // settling closure invariant
}

// 4/5. Mounts — witnessed configuration
mount(manifest: MountManifest, provenance: ProvenanceTerm): Promise<MountOutcome>;
unmount(name: AddressTerm, provenance: ProvenanceTerm): Promise<MountOutcome>;  // drops RAM, keeps log

// 6. Trace access — the log is servable truth
trace(subject: AddressTerm, cursor?: LogCursor): AsyncIterable<TraceRow>;
selfTrace(cursor?: LogCursor): AsyncIterable<DaemonWitness>;   // ticks, errors, mounts, quarantines

// 7. Quarantine re-judgment — admission of provenance is evidence
supplyProvenance(id: CanonicalId, evidence: ProvenanceWitness): Promise<AdmissionOutcome>;

// 8. Crash-recovery / audit verb
refold(options?: { verify?: boolean }): Promise<RefoldReport>;  // replay logs, compare checkpoint, witness divergence

// Lib seam (demands on @emsenn/meme-topology, §3)
resume(carrier: MemeTopologyCarrier, delta: readonly Attestation[], fuel?: Natural): ResumeResult;
cellDelta(before: MemeTopologyCarrier, after: MemeTopologyCarrier): CellChangeSet;
encodeAttestation(a: Attestation): AttestationWire;  decodeAttestation(w: AttestationWire): Attestation;
encodeOrdinalTerm(o: Ordinal): OrdinalTerm;          decodeOrdinalTerm(t: OrdinalTerm): Ordinal;
```
